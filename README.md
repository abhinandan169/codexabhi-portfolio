# ⚙ Installation

## Clone Repository

```bash
git clone https://github.com/abhinandan169/codexabhi-portfolio.git
```

## Backend

```bash
cd backend
pip install -r requirements.txt
python server.py
```

## Frontend

```bash
cd frontend
npm install
npm start
```
